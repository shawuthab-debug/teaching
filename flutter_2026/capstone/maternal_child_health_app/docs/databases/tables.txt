
## Database Tables

### user table (Master Table)
| Field | Type | Description |
|-------|------|-------------|
| id (PK) | INT | Unique ID |
| name | VARCHAR | Full name |
| phone | VARCHAR | Contact number |
| password | VARCHAR | Hashed password |
| role | VARCHAR | Mother, Health Worker, or Admin |

### mother table
| Field | Type | Description |
|-------|------|-------------|
| id (PK) | INT | Unique ID |
| user_id (FK) | INT | Links to user |
| dob | DATE | Date of birth |
| village | VARCHAR | Home address |
| due_date | DATE | expected_delivery_date |
| owner_id (FK) | INT | Links to user |

### child table
| Field | Type | Description |
|-------|------|-------------|
| id (PK) | INT | Unique ID |
| mother_id (FK) | INT | Links to mother |
| name | VARCHAR | Child's name |
| dob | DATE | Date of birth |
| sex | VARCHAR | Gender |
| birth_weight | DECIMAL | Child weight after birth|
| owner_id (FK) | INT | Links to user |

### visit table
| Field | Type | Description |
|-------|------|-------------|
| id (PK) | INT | Unique ID |
| mother_id (FK) | INT | Links to mother |
| health_worker_id (FK) | INT | Links to user |
| child_id (FK) | INT | Links to child |
| visit_date | DATE | Date of visit |
| bp | VARCHAR | BP reading |
| weight | DECIMAL | Weight in kg |
| notes | TEXT | Observations |
| owner_id (FK) | INT | Links to user |

### vaccination table
| Field | Type | Description |
|-------|------|-------------|
| id (PK) | INT | Unique ID |
| child_id (FK) | INT | Links to child |
| vaccine | VARCHAR | Vaccine given |
| date_given | DATE | Date given |
| date_due | DATE | Next dose date |
| status | VARCHAR | pending, given and missed |
| owner_id (FK) | INT | Links to user |

### reminders table
| Field | Type | Description |
|-------|------|-------------|
| id (PK) | INT | Unique ID |
| user_id (FK) | INT | Links to user |
| message | VARCHAR | reminders to mother, healthworkers and admin |
| send_date | DECIMAL | scheduled time before the appointments |
| sent | BOOLEAN | true or false |
| owner (FK) | INT | Links to user |

### appointments table
| Field | Type | Description |
|-------|------|-------------|
| id (PK) | INT | Unique ID |
| user_id (FK) | INT | Links to users |
| appt_date | DATETIME | Scheduled time |
| status | VARCHAR | Pending, Attended, Missed |
| type |VARCHAR | antenatal|
| owner (FK) | INT | Links to user |
PK -PRIMARY KEY
FK -FOREIGN KEY
